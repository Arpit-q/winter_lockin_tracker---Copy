# Winter Arc Lock-In — Solo Leveling Command Center 🗡️

A dark fantasy, gamified execution tracker for the **October 1 → December 31, 2026** Winter Arc sprint.

Transform your daily academic, coding, research, and engineering goals into an immersive **Solo Leveling "Player / System" experience** designed to push your limits every single day.

---

## ⚡ Solo Leveling System Features

### 1. 🛡️ Status HUD & EXP Leveling
- **Hunter Ranks**: E-Rank (Lv 1–10) → D-Rank (Lv 11–25) → C-Rank (Lv 26–45) → B-Rank (Lv 46–70) → A-Rank (Lv 71–90) → S-Rank (Lv 91–99) → **Shadow Monarch (Lv 100+)**.
- **Dynamic EXP System**: Every question solved (+15 XP), LOC shipped (+20 XP/100 LOC), topic mastered (+35 XP), and deep work hour (+50 XP) directly increases your Hunter Level.
- **Holographic HUD**: Real-time Level, Tier, Title, EXP Progress Bar, and Winter Arc Day (Day X of 92) countdown.

### 2. 📊 Abundant Pie Charts & Visual Growth Indicators
- **Domain Output Distribution Donut**: Visual split across Academics, Agentic AI, ML Project X-0, and Deep Work.
- **Academic Subject Problem Allocation Donut**: Mathematics III vs COOS vs Python vs DSA vs UHV.
- **Daily Quest Completion Donut**: Real-time percentage cleared with glowing center.
- **Skill Depth Mastery Donut**: Depth distribution across Agentic AI & X-0 topics (Depths 0 to 5: Unexplored to Master).
- **Functional Output Type Donut**: Code Shipped vs Problem Solving vs Deep Work & Stamina vs Theory & Research.
- **Today's EXP Forge Breakdown Donut**: Instant visual breakdown of where today's XP came from.
- **5-Dimensional Hunter Attribute Polygon (Plotly Radar)**: INT (Academics), STR (Code Execution), PER (Research Depth), AGI (Agentic AI), VIT (Deep Work Stamina).
- **Winter Arc Timeline Pace Gauge**: Track whether your grind pace is ahead or behind schedule.
- **Cumulative EXP Area Trajectory**: Visual progression curve toward Level 100.

### 3. 📜 Daily Quests & Custom Goals
- **[ DAILY QUEST: PREPARATION TO BECOME A MONARCH ]**:
  - 10+ Mathematics III Questions
  - 5+ DSA / LeetCode Problems
  - 150+ Lines of Python Code
  - 2+ Agentic or X-0 Topics Mastered
  - 3.0+ Hours of Deep Work
- **Quest Rewards**: Instant +250 Bonus EXP and celebratory animations upon 100% daily completion.
- **Custom Goals**: Add and check off personalized daily micro-tasks with custom XP rewards.

### 4. 🏆 Hunter Achievements Gallery
- Unlockable trophies (Common, Rare, Epic, Legendary) with live progress bars:
  - *First Awakening*, *Iron Will (7-day streak)*, *Math Berserker*, *Syntax Necromancer*, *Agentic Architect*, *Shadow Realm Monarch*, *National Level Awakened*, and more!

### 5. 📚 Specialized Mastery Tracks
- **Semester 3 Academics**: M3 chapter ledger, numericals, practicals, and weekly trends.
- **Agentic AI Mastery**: Phase 1–12 progression curriculum, depth distribution, and topic master list.
- **ML Project X-0**: Phase 0 100-topic ledger, mathematical derivations, and experiment logs.
- **Projects & Proof**: Production deployments, evidence links, and verifiable outcomes.

### 6. 💬 AI System Assistant & Shadow Companion (Groq Powered)
- **Embedded Neural Link**: In-app conversational AI directly accessible from the navigation deck.
- **Context-Aware Persona**: Grounded in Arpit's real-time Hunter level, EXP stats, and curriculum (Mathematics III, COOS, Python, DSA, Agentic AI, and ML Project X-0).
- **Tactical Presets & Real-time Streaming**: Quick-action prompt chips for M3 Cauchy-Euler derivations, LangGraph routing, attention math, and lock-in study schedules powered by ultra-low-latency Groq models.

## 🚀 How to Run

```bash
# 1. Activate environment
.venv\Scripts\activate

# 2. Run Streamlit
streamlit run app.py
```

Then open `http://localhost:8501` in your browser.

> **Tip**: Visit the **⚙️ Hunter Config & Reset** tab to personalize your Hunter Name and Title, or click **"Awaken with Realistic 7-Day Lock-In Sample Data"** to instantly test and preview all charts and visualizations!
